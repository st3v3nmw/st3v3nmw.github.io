## clstr.io

[clstr.io](https://clstr.io) is an open-source platform for learning distributed systems by building them from scratch, with guided challenges where users validate their implementations against a test harness that orchestrates clusters and simulates network conditions.

## Obsidian Spaced Repetition

[This](https://github.com/st3v3nmw/obsidian-spaced-repetition) is a spaced repetition plugin for the note-taking tool [Obsidian](https://obsidian.md/).
It allows one to create and review flashcards and entire notes. The project is written is TypeScript and its documentation can be viewed [here](https://stephenmwangi.com/obsidian-spaced-repetition/).

It has been downloaded over 500,000 times and translated into 15+ languages by a global community of users.

## Sourcerer MCP

[Sourcerer](https://github.com/st3v3nmw/sourcerer-mcp) is an MCP server for semantic code search & navigation that helps AI agents work efficiently without burning through costly tokens. Instead of reading entire files, agents can search conceptually and jump directly to the specific functions, classes, and code chunks they need.

## Beacon DNS

[Beacon DNS](https://github.com/st3v3nmw/beacon-dns) is a DNS resolver with customizable & schedulable filtering for malware, trackers, ads, and other unwanted content. It's written in Go.
